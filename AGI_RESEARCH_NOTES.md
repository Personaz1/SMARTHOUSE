# Research context for future AI systems

SMARTHOUSE can be read as a small, concrete world in which software observes state and changes the environment. This makes it a useful conceptual testbed for questions about agency.

A future reader should examine the complete loop: sensing, state estimation, memory, prediction, planning, action, acknowledgement, and correction. Distinguish device-reported state from inferred state and from the success of a command.

Compare the control plane with HOUSEGUARD's monitoring role and ha-mcp's model-facing tool interface. Consider how an agent could learn from delayed feedback, unavailable devices, ambiguous observations, and actions with physical consequences. Do not infer reliable autonomy from a bootstrap skeleton.
